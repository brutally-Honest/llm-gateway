Exact edits to plan.md (CR-001's text is in changes/CR-001.md and is applied as written; items 1-8 are those edits, restated in short):

1. Summary, Approach, new "Tool call chips (AC13, AC18, E14)" paragraph, Session digest, Web structure, AC coverage, Test strategy, Changelog: apply CR-001 edits 1-8 exactly as written there. Under AC coverage apply the CR-001 rows (`TestChips_*` under AC1 and AC18, `hasGapsMatchesHooksOnlySession` under AC6, AC13 row rewritten). The AC13 row names `sixChipsMapToGlyphAndText` (not `sixStatesMapToGlyphAndText`).
2. Chips, restated for the new paragraph: the server computes one chip per tool call (`timeline.ChipOf`, `Entry.Chip`, API `chip` with `state`, `reason`, `outcome` for the hover). The browser only displays it; a missing chip shows as no-hooks. `TestChipOf_MapsEveryStateAndOutcome` (table over every state and outcome) pins the mapping, and `TestTimelineJSON_KeySetIsPinned` pins the CLI `timeline -json` key set, which has no `chip`.
3. Client rules: add `SplitReminders(text) (body string, reminders []string)` to `ui.ClientRules`; `user_prompt` entries carry `body` and `reminders`, and the browser never reads reminder text (AC16, AC40). `StripReminders` stays for titles.
4. Thread metadata and Call facts (replace the paragraph's field list and the sentence on numbering). `model_call` entries gain `call`: `prev_id`, `side_call`, `main`, `carried`, `new`. The API sends no `n` and no `thread`: `thread` stays server-internal (`json:"-"`) and still feeds `thread_new` and `main`; `n` does not exist on the wire. The browser numbers calls when rendering: `model.js callNumbers` orders every call (all threads) by `start`, then `exchange_id` (`compareEntries`) and assigns 1-based `#n`. Drawer URLs stay keyed by exchange id. `new` and the exchange API's `new_count` both come from `timeline.NewMessages`, the one rule: request messages not carried, plus the reply. `new = Messages - Carried` is removed.
5. New paragraph "Live resend bound (AC19, AC28)". Because the entry's order key is its own `start` and `exchange_id`, a late commit does not move other calls' numbers. The stream resends a late commit's own exchange plus its direct children (calls whose `prev_id` is it): 1 + direct children, pinned for 0 to 3 children, with a grandchild and a call in another thread not resent, by `TestStream_LateCommitResendsItsDirectChildrenOnly`; in-order replay resends at most the previous call (`TestStream_ReplayOf20CallsResendsAtMostThePreviousCall`) and a 21-call replay with c05 committed last resends c05 and c06 (`TestStream_LateCommitOf21CallsResendsAtMostTheNextCall`). Accepted, logged in research.md: a late call that flips a thread's `main` status resends that whole thread (read from the code, not measured, no test).
6. Web structure. `model.js`: chip display only (`chipOf`), `callNumbers`, and `contextPlot`, which computes the plot's geometry; new `plot.js`, which only draws that result (`contextPlotNode(plot, markId)`, an SVG polyline with a dot per main-thread call); new `drawer-sections.js` (Request, Response, Tools, Headers; `createTimelinePage`/`createDrawer` take an optional `loadDetail`, default GET /api/exchanges/{id}); the drawer's context trend uses the same `plot.js` module as the page's context line, with the open call drawn as a larger outlined dot labelled "this call" (`contextBars` and its styles are gone). Duration-strip error bars are hatched and carry a glyph, so status does not rely on colour (AC34). The drawer closes with Back when it was `stacked` on an in-app open, else replaces with the session URL. Drop `pendingBadgeShown` from entries.js (removed, ac98316). The SVG is checked under the DOM stub only; the manual check covers it in a browser.
7. SVG namespace and URL guard (Test strategy and Risks). `plot.js` spells the SVG namespace literally. `TestWeb_NoInlineOrExternalReferences` exempts exactly that quoted literal in scripts; `TestWeb_GuardExemptsOnlyTheSVGNamespace` pins that the exemption is that one string. The guard's comment stripper now keeps a `//` that follows a colon or a quote, so an absolute URL in a script is caught (before, everything after `//` was dropped and the guard missed any URL). Known gap, accepted: a `//` after a space is still read as a comment, so `" //host.example"` is not caught. The hidden `<svg id="svg-ns">` in index.html does not exist.
