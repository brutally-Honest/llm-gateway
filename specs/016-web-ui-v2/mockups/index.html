016 web UI v2 · mockups

The chosen session page (variant 4 of the four drawn on 2026-11-10; the others are in git history) and the sessions list, on one made-up session (~/code/shop-api, 8 turns). The spec in specs/016-web-ui-v2/ wins where it differs from these pages.

Session page · story

Turns on the left, the story in the middle, Files, Commands, Sites and Context tabs on the right; only the middle scrolls. Each turn is a card with your prompt as its heading.

Every click opens one modal shape (facts, why it is attributed, diff or output, "Show in turn N"); "Needs a look" lists what deserves a second glance.

Sessions list

A table with readable titles for sessions with no prompt, labelled counts, effect counts per session, and the unassigned connection with its ⚙ harness label.

Kept from the variant round

  • Tool lines like ✓ Bash npm test · 2m 14s, ✓ Edit src/app.js +3 −1, ✓ Skill pdf, each with its run time; a failed tool says ✗ failed in words.
  • Effects under the tool call that caused them; the 015 label as glyph + word in a badge before the path. "Several running" effects sit once, after the parallel calls they name; harness and outside effects in their own group.
  • Turn time from prompt to final answer, split into model, tool and waiting time. Tool time leaves out the Agent call's span, whose sub-agent calls already count as model time.
  • Side calls folded behind "2 side calls", never red. Thinking and context size only in a call's details.
  • Paths relative to the session folder, full path on hover and in details. Turn 8 is hooks-only: "no model calls captured".
  • Dark by default with a light toggle, glyph + word for every status, every control a real button or link.
